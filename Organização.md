15. Agora sobre o GitHub

Aqui eu acho que podemos deixar o projeto muito mais organizado.

Você já criou:

GitHub do TCC + Kanban

Ótimo.

Eu sugiro que o GitHub seja o centro operacional do grupo.

Não quero que vocês tenham:

WhatsApp → "quem faz isso?"
Google Docs → "qual era a versão?"
GitHub → algumas coisas
Caderno → outras coisas

A ideia é:

GitHub = fonte oficial do projeto.

E o Kanban vira nosso painel de controle.

19. Uma regra que eu colocaria no Kanban

Toda tarefa precisa ter:

Responsável

Prazo

Descrição

Critério de conclusão

Por exemplo:

Implementar cálculo do resultado vocacional

Responsável: Guriz 2
Prazo: 14/09
Categoria: Backend/Lógica

Descrição:

Implementar o cálculo das pontuações obtidas no questionário.

Critério:

Ao finalizar o questionário, o sistema deve calcular as pontuações e identificar o perfil correspondente.

Isso é MUITO melhor do que uma tarefa simplesmente chamada:

"Fazer questionário"
